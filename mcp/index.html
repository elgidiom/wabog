Conecta Wabog con tu IA

El conector oficial de Wabog (un servidor MCP) permite que tu asistente de inteligencia artificial consulte tus procesos judiciales, tu calendario y tus tareas, y trabaje con ellos por ti. Sin claves ni configuraciones complicadas: inicias sesión con tu cuenta de Wabog y listo.

https://mcp.wabog.com

La forma fácil: deja que tu IA lo configure

Descarga este archivo y compárteselo a tu asistente (arrástralo al chat o guárdalo donde tu herramienta lee skills) con un mensaje como: «Configura el conector de Wabog siguiendo este archivo». La IA detectará tu entorno y hará la configuración por ti.

Antes de empezar

  • Necesitas una cuenta de Wabog con una compañía en plan pago activo. Si aún no la tienes, crea tu cuenta en app.wabog.com.
  • La conexión usa el inicio de sesión seguro de Wabog (OAuth). Nunca tendrás que copiar ni pegar claves o tokens: tu herramienta abrirá el navegador para que inicies sesión y apruebes el acceso.
  • La dirección del conector es siempre la misma: https://mcp.wabog.com (si tu herramienta pide una ruta con /mcp al final, también funciona).

Configuración por herramienta

ChatGPT

  1. Abre Configuración → Apps y conectores.
  2. Busca Wabog en el directorio de apps y pulsa Conectar. Si aún no aparece publicada, activa el modo desarrollador y crea un conector con la URL https://mcp.wabog.com.
  3. Inicia sesión con tu cuenta de Wabog y aprueba el acceso.
  4. Prueba escribiendo: «Muéstrame mi plan actual de Wabog».

Claude (web y escritorio)

  1. Ve a Configuración → Conectores → Añadir conector personalizado.
  2. Nombre: Wabog. URL: https://mcp.wabog.com.
  3. Pulsa Conectar e inicia sesión con tu cuenta de Wabog.

Claude Code

Ejecuta en tu terminal:

claude mcp add --transport http wabog https://mcp.wabog.com

Dentro de Claude Code escribe /mcp, elige wabog y completa el inicio de sesión en el navegador.

Codex (OpenAI)

Ejecuta en tu terminal:

codex mcp add wabog --url https://mcp.wabog.com
codex mcp login wabog

Si tu versión no tiene estos comandos, añade esto a ~/.codex/config.toml:

[mcp_servers.wabog]
url = "https://mcp.wabog.com"

Antigravity (Google)

En el panel del agente abre la configuración de MCP (Manage MCP Servers → View raw config) y añade:

{
  "mcpServers": {
    "wabog": {
      "serverUrl": "https://mcp.wabog.com"
    }
  }
}

Guarda, refresca los servidores y completa el inicio de sesión cuando se abra el navegador.

OpenCode

Añade esto a tu opencode.json (en el proyecto o en ~/.config/opencode/):

{
  "mcp": {
    "wabog": {
      "type": "remote",
      "url": "https://mcp.wabog.com",
      "enabled": true
    }
  }
}

Al usar una herramienta de Wabog por primera vez, OpenCode abrirá el navegador para autenticarte.

Cualquier otra herramienta compatible con MCP

Usa la opción de tu herramienta para añadir un servidor MCP remoto con la URL https://mcp.wabog.com y transporte Streamable HTTP. La autenticación se hace sola mediante OAuth: solo debes iniciar sesión con tu cuenta de Wabog.

¿Qué puede hacer tu IA con Wabog?

  • Consultar tus compañías, tu plan y sus capacidades.
  • Buscar procesos judiciales y revisar su ficha completa: despacho, sujetos procesales, actuaciones y audiencias.
  • Crear procesos nuevos a partir del radicado y asignarles un alias.
  • Ver tu calendario unificado de tareas, términos y audiencias.
  • Listar, crear y actualizar tareas.
  • Consultar y ajustar tus preferencias de notificación por correo y WhatsApp.

El conector solo accede a la información que tu cuenta ya puede ver en Wabog, y cada acción respeta los mismos permisos de la aplicación. No administra tu plan ni comparte datos con terceros.
